# Agent guide

This repository is **Planchette**, a simulator for a large multitouch table that
also tracks physical pucks.

- Working on the **simulator itself**: read `CLAUDE.md`.
- Writing an **interface that runs on the table**: read `docs/DESIGN-RULES.md`
  and `docs/API.md`. Almost nothing in `CLAUDE.md` applies.

`CLAUDE.md` and this file carry the same guidance; different tools look for
different filenames.
