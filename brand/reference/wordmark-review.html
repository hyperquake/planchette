Planchette wordmark

Planchette is a Hyperquake tool, not a brand of its own. The lockup is deliberately quiet: brand typeface, no custom letterforms, no second accent. The mark carries the personality, the type stays out of the way.

A. Horizontal lockup Recommended

The default, and the only one that should appear in the product UI, the site header, or a docs page. The mark stands 1.52 cap heights tall and its optical centre sits on the cap band, so the point and the heel balance around the letters rather than floating above them.

Clear space and minimum size

Clear space is one mark height on all sides, measured from the bounding box of the whole lockup. Below 120px wide the type stops holding together, so use the mark on its own.

Production note

The type on this sheet is live, so it renders in Untitled Sans on a machine that has it and Helvetica everywhere else. Both are approved, but the shipped lockup should be outlined once from the licensed font and then used as artwork, so a missing font can never quietly change the lockup. The SVGs in the bundle are for development use and still reference the font by name.
